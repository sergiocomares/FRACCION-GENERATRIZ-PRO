# FRACCIÓN GENERATRIZ – PRO vs PRO MAX

Actividad web estática para practicar la obtención de fracciones generatrices a partir de decimales exactos, periódicos puros y periódicos mixtos. Incluye seis ejemplos disponibles de cada tipo.

## Uso

Abre `index.html` en un navegador moderno o sirve esta carpeta con un servidor HTTP estático. La aplicación carga MathJax desde jsDelivr para representar la notación matemática; por ello necesita conexión a Internet para el renderizado LaTeX.

El alumnado:

1. Escribe su nombre y completa ocho ejercicios elegidos aleatoriamente: dos exactos, tres periódicos puros y tres periódicos mixtos.
2. Identifica primero si el decimal es exacto, periódico puro o periódico mixto. Después sigue el método **PRO** y completa la igualdad entre la fracción inicial y el resultado final. Tras acertar, puede consultar el desarrollo algebraico **PRO MAX**.

En los decimales exactos, el resultado se completa automáticamente a partir de la construcción inicial. En los periódicos, hay una calculadora flotante limitada a restas para apoyar el cálculo del numerador.
3. Tiene hasta tres oportunidades de error por ejercicio, contando los fallos al identificar el tipo de decimal y al comprobar la fracción. Cada error reduce el valor de ese ejercicio en una veinticuatroava parte de la nota final; un ejercicio agotado no resta los puntos obtenidos en otros ejercicios. Al tercer error se muestra la solución y puede continuar con el siguiente ejercicio.
4. Consulta el informe final, que muestra la calificación sobre 10, los errores, el descuento aplicado y un recordatorio de que puede repetir la actividad tantas veces como desee. Después pulsa **PREPARAR CAPTURA PARA CLASSROOM** para mostrar únicamente el informe listo para capturar.

No se envía ni se detecta ninguna captura de pantalla: el alumno debe realizarla y adjuntarla manualmente en Google Classroom.
